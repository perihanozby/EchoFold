# Test report

Executed on 14 November 2026 with the installed Godot 4.7.2 stable Windows binary. Latest full regression counts and final artifact hashes are recorded in `build/final-verification.txt` after the final build.

Core/campaign runner: 545 checks, zero failures at the most recent execution. Covers horizontal/vertical involution, mirror transforms, fold isolation, invalid bounds/request, exact undo/redo/reset, reflection tables, all 60 schema/unique-start/unsolved-start/solver/par/determinism/JSON checks. Development-only solution fixtures are written to `tests/verified_solutions.json`.

Integration runner: 496 checks, zero failures in the final build run. Combined total: 1041 checks, zero failures. Covers save round trip, backup recovery from corrupt primary, partial valid data, future-version protection, independent daily records, settings, all UI key columns, straight/mirror/blocker/directional/channel optics, splitter loops, bounded solver, every daily date in 2026, real main-scene navigation, touch ownership/cancellation, hints, fold completion, UI history, restored redo including invalid entries, six viewport board geometries, 16-language screen construction/RTL and bundled font glyph coverage.

Visual runner: actual desktop OpenGL execution using NVIDIA GeForce MX130 and Intel UHD Graphics on separate runs. Captured six PNGs with successful save results and no GDScript exceptions. Inspected home, first light, resonance, completion, compact and Arabic settings. Final captures wait for entrance animations to finish. Detected/fixed undersized board. Compact screenshot demonstrates deliberate vertical scrolling. These are visual observations, not FPS or Android compatibility measurements.

Some sandboxed Godot processes emit an OS root-certificate-store access error and load the engine's built-in CA store. The game makes no network requests. Editor snapshot storage can also report denied access to the default user-data location under the workspace-only sandbox. Portable editor settings, gameplay desktop saves and automated fixtures are kept inside the workspace. File logging is explicitly disabled for desktop to avoid writing to the default external user-data directory. Occasional audio playback resources are reported by Godot on immediate test shutdown; no growth/performance impact has been measured.

The user explicitly approved phone installation and device QA. ADB detected a Redmi Note 9S, Android 11, 1080×2400, ARM64/Adreno 618. The universal build failed for storage; the first smaller ARM64 build installed and launched successfully. Manual play produced 13 campaign completions and one daily completion in the observed save. App-only force-stop/cold-relaunch retained those records and settings; restored home screenshot shows 13/60. Inspected process-only logs show no GDScript exceptions. MIUI denies ADB touch injection, so full automated gesture/system-back testing is BLOCKED. Audio/haptic confirmation remains pending; haptics were off in settings.

The phone revealed the default engine boot image and letterboxing; source and final artifacts now use original splash images and expand-aspect layout. Both corrected APKs are rebuilt and signed, but the corrected phone update was rejected for insufficient storage. The previous installed game and user progress were retained. No user files/caches were deleted or device security/storage settings changed. One debug memory snapshot measured PSS 285,591 KB, RSS 368,244 KB; sustained performance is NOT TESTED.
